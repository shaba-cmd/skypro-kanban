# Проект

Канбан доска для управления задачами.

## Стек технологий

React + Vite (с библиоткеами - react-router, axios, react-toastify, styled-components, @dnd-kit/core, /sortable, /utilities), 
JS, API.

## Визуал

При первом вхоже нас встречает страница авторизации с формой, через которую можно попасть на страницу регистрации
по кнопке "Регистрируйтесь здесь".

После авторизации/регистрации попадаем на канбан доску, в которой будет написано "Новых задач нет"
либо 5 колонок с статусами (Без статуса, Нужно сделать, В работе, Тестирование, Готово) 
в которых находятся картачки с задачами, если аккаунт уже был и на нем они создавались

Присутствует хедер с логотипом, кнопкой содания задачи и профиль.

Модалка создания задачи выглядит следующим образом, Модально окно с крестиком для закрытия окна, 
форма с полями - "Название задачи", "Описание задачи", Категории, Даты и кнопка "Создать задачу".

По нажатию на свое имя в хедере, появляется меню с именем, почтой, сменой темы и выходом

Картачки с задачами содержат в себе категорию, три кнопочки, которые дают понять, что можно открыть задачу, название задачи, дата.

При открытии задачи появляеться модалка похожая на окно при создании задачи
из отличий появилось название задачи, статус и кнопки редактирования под которой при открытии находить (сохранить, отменить, закрыть), удаления, закрытия

## Адаптив

Приложение полностью адаптированно под все размеры экрана (2560px - 320px)
все модалки и оповещения адаптированы

## Функциональность

При запуске приложения появляется Loader - Скелет(shimmer), которое дает нам понять, 
что страница загружаеться 

Можно создавать задачи по кнопке "Создать новую задачу" в хедере, либо снизу, если приложение открыто на телефоне
Задача отправленная без заполнения формы (название, описание, категория и дата), по умолчанию будет с названием - "Новая задача 1!",
Описание останется пустым, категория "Reserch", а дата установиться текущая.
Модальное окно закроется, если задача будет успешно выполнена, либо ее можно закрыть по нажатию на крестик.

После создания задачи ее можно будет открыть (Нажав на карточку) и посмотреть, либо отредактировать 
по специальной кнопке "Редактировать задачу", которая покажет еще три кнопки 
(Сохранить, Отменить - если было какое-либо изменение, Закрыть - что бы свернуть эти три кнопки), 
если на нее нажать поле ввода описания и дата станет доступными для изменения.
Рядом с кнопкой редактирования находиться кнопка "Удалить", которая удаляет задачу полностью.
И последняя кнопка "Закрыть", закрывает модальное окно с задачей.

В своем профиле можно менять тему с светлой на темную по нажатию на ползунок, 
либо выйти на кнопку "Выйти", откроется модалка с названием "Выйти из аккаунта?" с двумя кнопками, первая "Да, выйти", которая выходит из аккаунта и возвращает на страницу авторизации,
и "Нет, остаться", которая возвращает нас обратно на главную.

Авторизация/Регистрация осуществленна с помощью API, отправляем туда данные при регистарции и получаем созданый token который позже будет использован
для входа в аккаунт, получения задач, изменения, добавления и удаления их

## Доп. Функциональность

Loader - Скелет(shimmer)

Drag & Drop - карточки можно перемещать с колонки на колонку, при перемещении меняеться их статус. 
Чтобы переместить на телефоне нужно зажать пальцем карточку и потащить.
Данного функционала удалось добиться благодаря библиотеки @dnd-kit/core, /sortable, /utilities и нейросети Kimi

При каждом измении, при создании задачи и т.п. приходит оповещение снизу справа,
которое оповещает о событии которое удалось сделать (например: 'Статус обновлён!'), либо не удалось (например: 'Ошибка! Откатываем...')
Данного функционала удалось добиться благодаря библиотеки react-toastify

Календарь можно листать вперед и назад, выбирать дату, все прекрасно работает
в ее создании помогала нейросеть Kimi
